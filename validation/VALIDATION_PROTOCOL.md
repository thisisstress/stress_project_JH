# 스트레스 예측 모델 검증 프로토콜 V2

## 왜 변경했는가

V1~V4 개발 과정에서 동일한 5-Fold Seed `42`, `2026`, `3407`을
모델 구조, 분위수, 피처 복제 수와 블렌드 비율 선택에 반복 사용했다.
모델 간 비교 조건은 비슷했지만, 반복적인 선택으로 CV Fold 자체에
과적합될 위험이 커졌다.

## 새로운 검증 구조

1. 모든 후보는 완전히 동일한 Fold를 사용한다.
2. 타깃을 10개 분위 구간으로 층화한다.
3. 입력 피처가 완전히 같은 행은 하나의 그룹으로 묶어 같은 Fold에 둔다.
4. 모델 Random Seed는 `42`로 고정해 모델 구조 차이만 비교한다.
5. 기존 Seed는 `development`로만 표시한다.
6. 이전에 사용하지 않은 `104729`, `130363`, `155921`을 `audit`로 사용한다.
7. 절대 MAE뿐 아니라 V1과의 행 단위 쌍대 오차 차이와 95% Bootstrap
   신뢰구간을 계산한다.

## 제출 후보 승격 기준

- Development 평균 MAE가 V1보다 좋아야 한다.
- Audit Seed 3개 중 최소 2개에서 V1을 이겨야 한다.
- Audit 평균 오차 차이가 음수여야 한다.
- 쌍대 오차 차이의 95% 신뢰구간 상한이 0 이하이면 강한 후보로 본다.
- 신뢰구간이 0을 포함하면 개선이 불확실하므로 제출 횟수를 소모하지 않는다.
- 블렌드 비율은 Public 점수가 아니라 Train-only OOF에서 미리 고정한다.

## 해석상 주의

새 Audit Fold도 Train 데이터에서 만들어지므로 실제 Test 분포를 완전히
대변하지는 않는다. 또한 V1~V4 설정은 과거 전체 Train CV를 보며 정했으므로,
이번 Audit 결과는 완전히 순수한 외부 검증이 아니라 더 엄격한 재감사에 가깝다.
앞으로 새 모델은 Development에서만 조정하고 Audit 확인 횟수를 제한한다.
