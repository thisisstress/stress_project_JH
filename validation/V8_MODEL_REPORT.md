V7을 유지합니다.

## 고정 모델

V7은 다음 구조를 그대로 사용합니다.

- 중요 피처 복제를 적용한 ExtraTrees 1,200개
- 개별 Tree 예측의 52% 분위수
- V6 Tree 예측 85% + 모든 2차원 부분공간 1-NN 분위수 15%

V8 최종식은 다음과 같습니다.

```text
round(
    0.825 × V7
  + 0.025 × triple_closest30_q50
  + 0.050 × dimension4_q50
  + 0.075 × pool_dimension2to4_q48
  + 0.025 × pool_dimension2to4_q50,
  2
)
```

8개 고정 피처는 `mean_working`, `bmi`, `cholesterol`, `height`, `glucose`,
`weight`, `cholesterol_glucose_ratio`, `bone_density`입니다. 각 피처는 Train
분포만으로 경험적 순위로 변환합니다.

- `triple_closest30_q50`: 56개 3차원 조합 중 해당 행과 Train 이웃의 거리가
  가장 짧은 30개 target 중앙값
- `dimension4_q50`: 70개 4차원 조합의 최근접 Train target 중앙값
- `pool_dimension2to4_q48/q50`: 28개 2차원, 56개 3차원, 70개 4차원 최근접
  target을 합친 풀의 48%·50% 분위수

## 누수 방지

- 전처리기, 결측 중앙값, 경험적 순위와 모델은 Train에서만 학습합니다.
- CV에서는 동일 입력 중복 그룹을 한 Fold에 함께 배치합니다.
- Test 통계, 범주 빈도, 평균, 행 수, 인덱스와 순서를 사용하지 않습니다.
- Test의 다른 행을 참조하지 않습니다.
- 파생변수는 각 행 안에서만 계산합니다.
- 외부 데이터와 타 팀·과거 대회 코드를 사용하지 않습니다.
